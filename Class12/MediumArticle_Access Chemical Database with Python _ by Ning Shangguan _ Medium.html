Access Chemical Database with Python

Unlocking Complexity of Chemical Names

Ning Shangguan

The realm of chemicals is vast, encompassing both natural compounds and those synthesized by humans. We’ve produced an astonishing number of chemical substances — millions, to be precise. Among these, at least 160 million are well-documented. It is very hard for anyone can memorize even a small portion of it.

Adding to the challenge is the fact that many chemicals go by different names. For instance, toluene can also be referred to as methyl benzene, while xylene answers to dimethyl benzene. It’s a common occurrence to encounter multiple seemingly distinct chemical names that actually denote the same compound.

So, how do we efficiently identify and manage this chemical labyrinth? The answer lies in chemical IDs. By utilizing chemical databases, we can retrieve essential information about specific compounds. Fortunately, there are excellent online free chemical databases that provide basic details on various chemicals.

Now, picture this scenario: you’re dealing with an extensive chemical inventory containing tens of thousands of entries. Most of the chemicals do not have IDs, and many are duplicated under different names ( If you have the experience of handling laboratory chemicals, you will know this situation can often happen if the inventory is not well maintained). How can you do data cleaning of the chemical inventory without resorting to tedious manual searches?

Enter the solution: a straightforward Python code that interacts with chemical databases via APIs. Let’s explore two commonly used online databases — ChemSpider and PubChem — to demonstrate how Python can streamline the retrieval of chemical IDs and related information.

Chemical Data Base API

1. ChemSpider

ChemSpider is a free online chemical database owned by Royal Society of Chemistry. To access the API, there is already a python package called chemspipy. You just need to install the package either by “pip install chemsipy” or “conda install -c conda-forge chemspipy”.

An API KEY is required by the ChemSpider, you get one by registering a free account. Let’s store the API KEY in the .env file and give a try to search the chemicals.

import os
from dotenv import load_dotenv
load_dotenv()
from chemspipy import ChemSpider

key=os.environ['API_KEY']
cs = ChemSpider(key)
c2=cs.search('toluene')

Let’s check the search results:

c2[0]

Perfect! How about other properties?

print(c2[0].csid)
print(c2[0].common_name)
print(c2[0].molecular_formula)
print(c2[0].average_mass)

The output is:

Good! We can use the python code and chemspipy package to get all the basic information of chemicals.

Still there are some drawbacks of using ChemSpider API, first it is only free for 1000 searches per month. Second, some chemical abbreviation is different from our common practice (for example: THF should be tetrahydrofuran but it gives tetrahydrofolic acid as the search result). Third, the chemical ID they use is called chemspider ID, the most commonly one, CAS number, is not easily available.

2. PubChem

PubChem is a free chemical database maintained by National Library of Medicine (a subsidiary of NIH). It provides free API access with unlimited searches. A python package called pubchempy can provide all the access functions.

We only need to run “pip install pubchempy” to install the package. Unlike the ChemSpider we mentioned above, no API KEY is required to access the database and it is FREE no matter how many times you search. Let’s see how it works.

import pandas as pd
import numpy as np
import re
import pubchempy as pcp

We can use the get_syonyms method to get all the syonyms of a chemical:

print(pcp.get_synonyms('benzene', 'name'))

The output is:

Wow, so many different names for a common chemical! Pubchem also has their own chemical ID system called Pubchem CID, which is easily available from pcp.get_synonyms(‘chemical_name’, ‘name’)[0][‘CID’]. You can notice that the CAS number is among the synonyms output too. Since the CAS number is the most common ID, we should write a function to get the CAS number.

def get_cas(name):
    cas_list=[]
    try:
        results = pcp.get_synonyms(name, 'name')
        for result in results[0]['Synonym']:
            match = re.match(r"(\d{2,7})-(\d\d)-(\d)", result)
            if match:
                cas_list.append(match.group(0))
 
    except:
        cas_list.append(np.nan)
    return cas_list[0]

The most common name is the first one in the synonyms list. So we can write a function to get the common name.

def get_name(name):
    try:
        results = pcp.get_synonyms(name, 'name')
        return results[0]['Synonym'][0]
    
    except:
        return np.nan

We also write functions to get molecular weight and molecular formula.

def get_molecular_weight(name):
    
    try:
        compound = pcp.get_compounds(name, 'name')
        return compound[0].molecular_weight
    
    except:
        return np.nan

def get_molecular_formula(name):
    
    try:
        compound = pcp.get_compounds(name, 'name')
        return compound[0].molecular_formula
    
    except:
        return np.nan

Let’s package all the above code in one function:

def create_chemical_dataframe(chem_list):
    CAS_list = []
    mw_list = []
    mf_list = []
    nm_list = []

    for name in chem_list:
        cas = get_cas(name)
        CAS_list.append(cas)

        mw = get_molecular_weight(name)
        mw_list.append(mw)

        mf = get_molecular_formula(name)
        mf_list.append(mf)

        nm = get_name(name)
        nm_list.append(nm)

    chem_df = pd.DataFrame({
        'name': chem_list,
        'common_name': nm_list,
        'cas': CAS_list,
        'molecular_weight': mw_list,
        'molecular_formula': mf_list
    })

    return chem_df

Let’s test run the code with a chemical name list:

chem_list = ['ETHYL CAPROATE', 'THF', 'ISOAMYL ACETATE', 
'METHYL 2-METHYLBUTYRATE', 'METHYL ANTHRANILATE', 'isopropanol', 
'IPA wipes', '2-propanol', 'Rubbing alcohol',
'acetonol']
chemical_dataframe = create_chemical_dataframe(chem_list)
chemical_dataframe

The output is:

Yeah! We get all the expected results. The code successfully found 5–8 belong to the same chemical. The entry 9 is a name with mistake so it only yields null value.

Conclusion

We can see if we use python together with the chemical database API, it will become a powerful tool to clean your chemical inventory datasheet. Thanks to the free online database and API, handling thousands of chemical names is no longer a challenge.
